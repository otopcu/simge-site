### What's New

SimGe 0.5.0 is now available. This release also includes the 0.5.0.1 update.

- Work with large modular FOMs more comfortably through faster, searchable, dependency-aware data-type selection in the Object Model Editor.
- Validate standalone modules and composed dependency closures more clearly with improved FDD validation scopes, toolbar feedback, and unresolved-reference reporting.
- Preserve dependency-defined data-type references more safely during modular import, export, and composition, reducing accidental data loss in standalone workflows.
- Review model health faster with dashboard and module-report findings for unresolved object, interaction, record, array, variant, and representation references.
- Explore refreshed NETN-CBRN, NETN-ENTITY, and NETN-MRM telemetry validation evidence with clearer reliability, clock-alignment, topology, and payload-hotspot reporting.
- Load large telemetry manifests more reliably in the Telemetry Visualizer thanks to direct property-set selectivity resolution and bounded legacy fallback behavior.
- Read updated public documentation covering release notes, architecture guidance, telemetry samples, and the current release process.
